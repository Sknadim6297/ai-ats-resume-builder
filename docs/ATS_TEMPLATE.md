# Universal ATS Template Plan

Single-column, ATS-friendly structure (HTML/PDF/DOCX generation comes later).

## Sections (fixed order)

1. **Contact Details**
   - Full name, headline, email, phone, location
   - LinkedIn / GitHub / portfolio URLs (plain text URLs preferred for ATS)

2. **Professional Summary**
   - 3–5 lines grounded in verified master profile
   - No invented claims

3. **Technical Skills**
   - Grouped by category when available
   - Prefer verified / primary skills first

4. **Professional Experience**
   - Reverse-chronological roles
   - Bullet achievements with measurable outcomes where available

5. **Selected Projects**
   - Ranked for the target JD (Phase 2+)
   - Technologies listed as plain text

6. **Education**
   - Degree, institution, dates, notable coursework/certs if relevant

## Formatting rules (future renderers)

- Single column only
- Standard fonts; avoid icons/graphics as primary content
- No tables for core content layout when avoidable
- Consistent date format
- Section headings as plain text

## Grounding rule

Generated content must only use approved master-profile data and explicitly
approved AI suggestions. Hallucinated experience/skills are out of scope.
